03 / DESIGN PROCESS

1차에서 3차까지,
뭉치가 뭉쳐지는 과정.

1차CONCEPT

감자 같은 덩어리 + 새싹

‘아직 완성되지 않았지만 계속 자라는 사람’을 둥근 실루엣과 작은 새싹으로 시각화했습니다.

2차SYSTEM

표정과 컬러 규칙 확장

작은 점 눈, 짧은 팔다리, 따뜻한 크림색을 중심으로 표정과 포즈가 변해도 동일한 인상을 유지하도록 시스템을 정리했습니다.

3차FINAL

캐릭터 시트 + 콘텐츠 활용

표정, 포즈, 소품, 컬러 팔레트와 만화 스타일을 하나의 시트로 완성해 SNS 콘텐츠 제작까지 확장할 수 있도록 구성했습니다.
