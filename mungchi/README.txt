뭉치 원페이지 포트폴리오

실행 방법
1. 폴더 안 index.html을 더블클릭해서 브라우저에서 실행합니다.
2. VS Code Live Server를 사용하면 더 안정적으로 확인할 수 있습니다.

구성
- index.html
- css/style.css
- js/main.js
- images/ 캐릭터 시트와 웹용 크롭 이미지

수정 포인트
- CONTACT 메일: index.html 하단 hello@example.com 변경
- 인스타 콘텐츠 문구: SOCIAL 섹션의 EP.01~EP.06 수정
- 실제 1차/2차 시안이 있으면 PROCESS 섹션의 SVG/시스템 미리보기를 이미지로 교체

※ Google Fonts를 사용하므로 인터넷 연결이 없으면 시스템 기본 폰트로 표시될 수 있습니다.
